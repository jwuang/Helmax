用户同时提供了 ui-ux-pro-max 的技能说明，已保存在仓库技能目录。

**助手提问：**

> 先从企业定位开始：请用一句话描述，你们主要为哪类客户提供什么产品或服务？例如：“为制造企业提供自动化设备与产线改造服务。” 暂时不用考虑宣传口号。

**用户：**

> 为制造类企业提供各类电子元器件设备

**助手继续询问产品范围：**

> 你说的“电子元器件设备”，主要是哪一类？这会决定首页的产品分类和图片方向。
>
> - 电子元器件为主，如芯片、电阻、电容、连接器
> - 生产或检测设备为主，如贴片机、测试仪、自动化设备
> - 电子元器件和设备都有，需要分别展示

注：用户随后用企业 PPT 提供资料；“需要分别展示”这一早期选项已被后续的统一产品展示要求覆盖。

**助手阶段答复：**

当前首页的视觉基础可以保留，业务内容和展示顺序需要重新梳理。面向制造类企业，首页应帮助客户看懂：你们提供什么、具备哪些能力、如何联系。

我检查了三语首页的桌面和手机效果，主要发现如下：

| 方面 | 当前情况 | 建议 |
| --- | --- | --- |
| 整体视觉 | 浅色背景、深青文字、留白和标题层级统一 | 保留简洁基调，结合企业品牌深化 |
| 首屏表达 | “以专业连接价值”等口号较抽象 | 明确企业身份、主营产品和服务对象 |
| 产品展示 | 目前展示“需求梳理、方案规划、协作支持” | 按实际产品类别组织，展示产品图片和用途 |
| 企业实力 | 缺少可供客户判断的真实资料 | 补充企业介绍，以及有依据的项目、资质或经营资料 |
| 图片与移动体验 | 建筑插画关联较弱；手机正文多为 13px，卡片篇幅较长 | 使用相关产品或场景素材，增大正文并优化图文比例 |
| 联系路径 | 联系页仍是待补充提示 | 补齐真实业务联系渠道 |

完整评估已保存到 [首页评估文档](HOMEPAGE-REVIEW.md)。

接下来，我们按这个顺序一步步做，每一步形成能直接查看、讨论的成果：

1. 明确需求：确定产品范围、主要访客和网站目标，形成一页需求简报。
2. 整理内容：确定栏目、企业资料和图片清单，形成网站结构。
3. 设计线框：安排首页模块和阅读顺序，先看桌面、手机的布局。
4. 确定视觉：结合 Logo、产品素材确定颜色、字体和图片风格。
5. 实现验收：在现有项目中落地，检查三语、移动布局和使用体验。

现在处于第一步。先确认一个会直接影响首页设计的问题：你说的“电子元器件设备”，是芯片、电阻、电容等元器件为主，还是生产／检测设备为主，或者两者都有？
