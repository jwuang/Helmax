# Helmax 全屏展览式首页草案

日期：2026-10-30。当前阶段：从内容线框推进到可滚动的本地视觉概念稿，用于讨论品牌表达、章节顺序与每屏节奏。前一版普通长页线框由本稿替代。

## 已确认的设计约束

- 网站用于企业介绍与展示，目标客户包括制造类企业。
- 对外统一使用 **Helmax** 名称及企业 PPT 中提供的 **Helmax Logo**。
- 导航为 **首页／关于企业／产品／联系我们**，正式网站保留简体、繁体和英文入口。
- 电子元器件、设备与工具在同一产品区域展示，共用卡片和图文样式；分类只用小标题或副标题。
- 首页采用一章一屏的展览式结构，每一屏表达一个主题。
- 企业文化／理念靠前，首屏的文案与主视觉共同表达理念。
- 企业文化关键词由用户明确为 **利他、专业、效率、创新**，当前文案与视觉围绕这四项展开。
- 整体气质具有科技感，使用品牌深蓝、冰蓝、青色点缀，以及精密网格、连接节点和克制动效。
- 加载时提供简洁的等待页面，完成准备后进入首页。

## 章节与构图

| 章节 | 主题 | 每屏构图与内容 | 浏览路径 |
| --- | --- | --- | --- |
| 01 | 品牌与理念 | 深蓝背景、大幅主题文案、精密网格与四个连接节点；搭配清楚的主营说明 | 主入口探索理念，次入口浏览产品 |
| 02 | 企业文化 | 浅冰蓝整屏、大标题与利他／专业／效率／创新四项理念，下方呈现使命和愿景 | 自然进入企业介绍 |
| 03 | 关于 Helmax | 品牌构图与简明企业介绍对位，说明产品覆盖与合作支持 | 进入产品展示 |
| 04 | 产品展示 | 元器件与设备工具共用一个陈列区域与卡片规则，以小标题分类 | 了解采购与服务支持 |
| 05 | 服务与能力 | 深色整屏，采用简洁的条目说明采购优化、库存支持、元器件质量与交付流程 | 进入联系与合作 |

## 首屏与文化表达

用户明确的企业文化关键词为 **利他、专业、效率、创新**。关键词已确定，以下口号、解释性文案和使命／愿景仍是面向网站的编辑草案。业务事实继续以企业 PPT 和后续资料为依据。

首屏大字：

> 以专业，
> 成就彼此。

业务说明：

> 面向制造企业，提供电子元器件、设备与工具，以及元器件采购与供应链支持。

文化章的四项展开：

- **利他**：理解客户与伙伴的需求，让合作建立在共同受益的基础上。
- **专业**：以产品知识与严谨流程，认真对待每一次采购与交付。
- **效率**：及时响应、清晰协同，让沟通与执行更有序。
- **创新**：持续改进服务与协作方式，寻找更合适的产品与供应方案。

使命草案：以专业与高效的服务，为客户及合作伙伴创造价值。

愿景草案：以开放协作与持续创新，连接制造所需。

首屏连接路径和几何结构以 Helmax 为中心，连接 ALTRUISM、EXPERTISE、EFFICIENCY、INNOVATION 四个节点。它是围绕文化关键词构成的科技视觉意象，不表示自研芯片、企业设施、供应网点或已测量的数据。图形用代码直接绘制，可随不同尺寸调整。

## 简洁加载页

- 画面只包含 **Helmax Logo、细进度线、“正在准备”** 三个元素，与整体冰蓝、深蓝视觉保持一致。
- 细线为不确定时长的加载提示，不显示无法核实的百分比。
- 首屏 Logo 和字体准备完成后立即进入；准备很快时直接显示首页，避免加载层闪烁。
- 等待超过 120ms 时显示加载层，最长 4.5 秒后自动释放页面；资源出错也会结束等待。
- 加载期间提供状态语义并暂时关闭背景交互，完成后恢复正文浏览和键盘操作。关闭 JavaScript 时直接展示内容。
- 减少动态效果时加载线静态显示，首页背景动效也关闭。
- 加载层属于进入首页前的状态，不作为额外的展览章节，也不增加导航项目。

## 全屏与滚动体验

- 每章以 `min-height: 100svh` 为起点，大屏内容量按一屏控制，页头与章末提示均预留空间。
- 正常滚动形成章与章之间的转换；桌面可使用轻量的 CSS 临近停靠，保留鼠标、触控和键盘的原生滚动。
- 右侧章节导航提供直接跳转，并标明当前章节。主要导航仍保持四项。
- 手机保留整屏起步与分段配色，文字或产品较多时自然延展；不会为凑一屏缩小正文或裁切内容。
- 首屏只有少量背景动效，正文默认可读。减少动态效果时关闭动效、平滑滚动与停靠，所有内容继续可用。

## 产品与资料

产品仍集中在第 4 章。统一的图片比例、标题与用途说明建立整体感，分类采用较轻的小标题。产品区同时呈现电子元器件和设备工具，不通过默认隐藏其中一类来制造分类效果。

设备示例和 Helmax Logo 直接取自企业提供的 PPT。元器件尚缺正式产品目录与图片，因此概念稿使用清楚标注的占位内容。正式型号、参数和图片在内容整理时补齐。

质量检查、BOM 与退换货等内容按 PPT 的元器件服务范围编排，不能推定为所有设备产品的统一承诺。当前联系资料尚未提供，概念稿如实保留待补提示。

## 本轮原型检查

- 使用本机 Chromium 149 检查 1440×900、1920×1080、1280×720、768×1024、390×844、320×740 六种尺寸，未记录横向溢出、缺失图片或页面脚本错误。
- 三种桌面尺寸下，六个章节的高度均分别为 900、1080、720px，实现每章一屏；手机和平板内容较多的章节自然延展，内容未被裁切。
- 检查了跳过导航、手机菜单、Escape 关闭、产品锚点跳转和菜单收起；减少动态效果时动效、平滑滚动与停靠均关闭。
- 检查了加载等待、准备完成、4.5 秒超时释放、Logo 加载失败和关闭 JavaScript 的场景；正文均可进入，完成后背景交互和忙碌状态正确恢复。减少动态效果时加载线保持静态。
- 桌面、手机与加载状态的 axe 自动检查在所选 WCAG 2 A/AA、2.1 A/AA 规则中未发现违规。
- 本轮检查针对独立的本地概念稿，尚未覆盖 Firefox、WebKit 或正式三语页面，未运行整个 Astro 项目的 `pnpm verify`。
